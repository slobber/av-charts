AvCharts
Get started API reference Gallery GitHub

A charting library for Avalonia, modelled on Flex's mx.charts

Axes, series, transforms and a drawing kernel, named the way mx.charts names them and built for readings rather than for sample data: a hundred thousand of them drawn in about thirty milliseconds, with sampling, gaps, second scales, data tips and a legend that switches a series off.

A first chart

var chart = new CartesianChart
{
    HorizontalAxis = new DateTimeAxis(),
    VerticalAxis = new LinearAxis(),
};

chart.Series.Add(new LineSeries<Reading>
{
    DisplayName = "Depth",
    ItemsSource = readings,          // whatever you have: a list, an array, a collection
    XSelector = reading => reading.When,
    YSelector = reading => reading.Depth,
});

The two packages come from NuGet, and one line in a page's resources dresses every chart on it: <ResourceInclude Source="avares://AvCharts.Controls/Themes/ChartTheme.axaml" />. The longer version has the whole of it.
